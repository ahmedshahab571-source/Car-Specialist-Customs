# Car Specialist Customs — Immobilizer Services Landing Page

A fast, mobile-first, conversion-focused landing page for **Car Specialist Customs** (Rochdale, UK),
dedicated to car immobilizer diagnostics, key programming and automotive key assistance.

## Features
- Lead generation focused: two enquiry forms + click-to-call CTAs throughout
- Mobile-first, fully responsive (phone / tablet / laptop / desktop)
- No frameworks — vanilla HTML, CSS and JavaScript (minimal, fast-loading)
- On-page SEO: semantic HTML5, meta tags, Open Graph/Twitter cards, `AutomotiveBusiness` + `FAQPage` structured data, sitemap & robots
- Accessible: labelled inputs, keyboard-friendly nav & FAQ, visible focus states, reduced-motion support
- Brand theme matched to the CSC logo (black / white / red)

## Structure
```
├── index.html          Main page
├── css/style.css       Styles (mobile-first)
├── js/script.js        Forms, nav, FAQ accordion, scroll reveals
├── assets/icons/       Logo (SVG)
├── favicon/            Favicon (SVG)
├── robots.txt
└── sitemap.xml
```

## Form handling (Formspree)
Both enquiry forms submit to **Formspree** (form `xgawzwkp`). Submissions are emailed to the
address configured on the Formspree form. On a new form, confirm the first submission via the
email Formspree sends before delivery is activated.

## Deployment
Static site — host anywhere (GitHub Pages, Netlify, Vercel, or any web server).
Before going live: add a 1200×630 social share image at `assets/images/og-image.jpg`.
